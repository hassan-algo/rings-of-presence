# SPARC rotation curves (Rotmod_LTG)

Mass models for 175 disk galaxies from Lelli, McGaugh & Schombert 2016, *AJ* 152, 157
(SPARC: Mass Models for 175 Disk Galaxies with Spitzer Photometry at 3.6 µm and Accurate Rotation Curves).

- Source: https://astroweb.case.edu/SPARC/ (also on Zenodo: https://doi.org/10.5281/zenodo.16284118)
- License: Creative Commons Attribution 4.0 International (CC BY 4.0)
- If you use these files, please cite Lelli, McGaugh & Schombert 2016, and the original rotation-curve sources where relevant.

Each `*_rotmod.dat` file lists, per radius: radius (kpc), observed speed and its error, and the speed contributions of gas, stellar disk and bulge (km/s).
